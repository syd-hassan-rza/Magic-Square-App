Magic Square Simulation & Solver (DSA Assignment 1)A Python desktop application built with Tkinter that visually constructs, simulates, and verifies magic squares of any valid order $n \ge 3$. The tool supports both direct $\mathcal{O}(n^2)$ constructive algorithms and search-based brute-force methods.📷 Application Preview
Figure 1: Main GUI window showing grid simulation, live statistics, and verification.🚀 Key Features & Functionality1. Constructive Generation ($\mathcal{O}(n^2)$)Automatically identifies the input order category and applies the exact mathematical algorithm:Odd Orders ($n \pmod 2 \ne 0$): Siamese (de la Loubère) method.Doubly Even Orders ($n \pmod 4 = 0$): 4×4 block diagonal/complement inversion.Singly Even Orders ($n \pmod 4 = 2$): Strachey’s method (4 sub-quadrants with column exchange rules).
Figure 2: Step-by-step constructive simulation with active cell highlighting.2. Search-Based Solvers (Brute-Force)Naive Permutation Search: Generates permutations of $1 \dots n^2$. Best suited strictly for $n = 3$.Backtracking with Pruning: Prunes invalid search paths early when row, column, or diagonal partial sums exceed or cannot reach the target magic constant $M(n)$.Non-Blocking UI: Runs search algorithms in background threads (threading) with user-defined timeouts and a live "Stop Search" cancellation control.
Figure 3: Backtracking search results, nodes explored, and execution metrics.3. Interactive Visual SimulationPlayback Controls: Start, Pause, Step-by-Step, and Reset.Speed Slider: Adjusts animation delay dynamically (10ms to 800ms).Step Highlighting: Highlights the active cell being populated along with explanation text.4. Verification & ValidationInput Validation: Gracefully detects and handles invalid inputs ($n < 1$, $n = 2$, non-integers).Mathematical Verification Panel: Computes target $M(n) = \frac{n(n^2 + 1)}{2}$ and displays row sums, column sums, diagonal sums, and square validity status.📂 Project Structure├── main.py           # Tkinter GUI, event handling, animation loop, and verification panel
├── constructive.py   # O(n^2) algorithms (Siamese, Doubly Even, Strachey's method)
├── brute_force.py    # Naive permutation and pruned backtracking solvers
├── README.md         # Project documentation and setup guide
└── screenshots/      # Directory for application screenshots
